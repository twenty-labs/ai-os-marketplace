# Field rules

| Field | Rule |
| --- | --- |
| Title and subtitle (App Store) | Do not repeat words across the two — each word is indexed once. Lead with the category term people search for. |
| Keywords (App Store, 100 characters) | No words already in title or subtitle; commas without spaces; no competitor brand names; singular or plural, not both. |
| Promotional text (App Store) | Not indexed; use it for timely messages — it can change without a new build. |
| Short description (Play, 80 characters) | Use all of it; include a commercial keyword; no slogans. |
| Full description (Play, 4000 characters) | The field Play indexes most strongly. Describe only features that exist in the current release; repeat the main terms naturally. |
| Screenshots | The first one states the outcome, never a login screen. Captions carry the words people search for (App Store indexes caption text). Show the real product. |
| Preview video | First seconds show the core action; it autoplays muted, so it must read without sound. |
| Age rating | Review the questionnaire before changing anything that touches it; a higher rating hides the app from filtered audiences. |
| Localization | The primary market's language is complete in both stores before secondary languages are polished. |

Every claim in a listing must be true of the current release; check the offer catalog and brand voice for what may be promised.
