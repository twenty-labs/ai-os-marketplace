# twentylabs — Twenty Labs AI OS plugins

Generated by `ai-os marketplace build` from @twentylabs/ai-os-registry 3.4.0. Do not edit by hand.
Each registry version is tagged `registry-<version>`; repositories pin that tag, or follow the `stable` ref,
in `.claude/settings.json` (written by `ai-os sync`), so they get exactly the roles and skills their `ai-os.yaml`
selects. Plugins carry no version: Claude Code updates them when the marketplace commit changes. To refresh by hand:
`claude plugin marketplace update twentylabs`, then `claude plugin update <plugin>@twentylabs`.
